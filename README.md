# helios-nova-scenarios

Code accompanying:

Lee JY et al.

*Characterising uncertainty in Nova classification of ultra-processed foods in existing dietary data: a scenario-based approach in a multi-ethnic Asian population*

This repository contains R code used to characterise uncertainty in applying the Nova food processing classification to food frequency questionnaire (FFQ) data from the HELIOS study.

Each of the 253 FFQ items was classified under three scenarios:

- Low processing (lowest plausible degree of processing)
- Primary (most plausible classification)
- High processing (highest plausible degree of processing)

The code derives Nova group intakes under each scenario and reproduces the figures and supplementary tables reported in the manuscript.

## Data availability

HELIOS participant data are not publicly available.

Researchers may apply for access through the HELIOS Data Access Committee (helios_science@ntu.edu.sg).
